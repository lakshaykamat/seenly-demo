Scoring fonctionnelle :
Scoring explication technico fonctionnelle:
Functional Definition of the Seenly Score (Single Block)
Seenly measures the real ability of a website to be visible, understood, and recommended
by search engines and by artificial intelligence engines.

The Seenly score is rated on 100 and is based on three measurable pillars, calculated
during a fixed analysis called a run.
1⃣ SERP Score — Google Visibility (0 to 100)
Weight in Seenly score: 30%
This score measures whether the website actually appears on Google for key business
queries.
Example:
10 tracked queries
the site appears in the top 20 results for 7 queries → 70% coverage
normalized average position → 65 / 100
➡ Final SERP Score: 68 / 100
“Your site is currently well visible on Google.”
2⃣ AI Score — Visibility in AI Engines (0 to 100)
Weight in Seenly score: 45% (main pillar)

This score measures whether ChatGPT, Gemini, and Claude actually cite or recommend the
website when a user asks relevant questions.
Seenly tests a predefined number of queries (e.g. 5)
A citation is counted only if at least 2 out of 3 AI engines cite the site (AI consensus)
Example:
5 AI queries tested
1 query with a consensus citation → 20%
➡ Final AI Score: 20 / 100
“Your site is very rarely recommended by AI engines.”
3⃣ AEO Score — Website Readability for AI (0 to 100)

Weight in Seenly score: 25%
This score measures whether the website is properly structured and understandable for AI
systems.
Number of pages analyzed (e.g. 5)
Each page is evaluated on 5 criteria:
topic clarity
heading structure (Hn)
relevant FAQ
structured data
internal linking
Example page scores:
80 / 60 / 70 / 50 / 60
➡ AEO Score: 64 / 100
“Your site is partially readable by AI engines.”
Seenly Score Calculation (Before Penalties)
SERP : 68 × 0,30 = 20,4
IA : 20 × 0,45 = 9
AEO : 64 × 0,25 = 16
⚠ Penalty Rules (Anti “False Good Score”)
Seenly applies strict rules designed to drive action.

• If IA Score = 0
→ the Seenly Score is capped at a maximum of 59 / 100
• If IA Score < 30
→ a –15% penalty is applied to the global score
Example:
• Raw Seenly Score: 70
• IA Score: 20
➡ Final Seenly Score = 70 × 0.85 = 59 / 100
👉 It is impossible to achieve a “good score” without AI visibility.

Technical & Functional Scoring Framework
1) Global Scoring Rules
R1 — Score per run, fixed
Each click on “Run an analysis” creates an AnalysisRun.
All scores (SERP / AI / AEO / Global) are calculated once, at the end of the run.
A run with status DONE is immutable (scores cannot be updated).
Any new measurement requires a new run.
R2 — Normalization
All sub-scores are integers between 0 and 100.
The global score is an integer between 0 and 100.
R3 — Transparency
Each displayed score must expose:
the inputs used (queries, engines, crawled pages)
the calculation formula
intermediate values (coverage, positions, citations, etc.)
