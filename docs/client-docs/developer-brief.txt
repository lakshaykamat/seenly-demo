Seenly AI
Developer Brief — Platform Build Specification

Project Objective
At the end of 8 weeks, Seenly must be enterprise-ready, multi-tenant, scalable, SOC2-ready at
baseline level, and fully operational across the three subscription plans: Starter, Growth, and
Enterprise.

1. Authentication & User Management
Full user authentication system including sign-up, login, password reset, and email verification.
Role-based access control (Admin, Member) with team and workspace management per tenant.
→ Google OAuth fully integrated and operational
→ Apple Sign-In fully integrated and operational

2. Email Infrastructure Setup
The developer must fully configure and deliver a production-ready email infrastructure. This includes
setting up a transactional email provider (SendGrid, Postmark, or Resend) with a verified sending domain
and proper DNS records (SPF, DKIM, DMARC) to ensure deliverability and avoid spam folders.
The following emails must be fully operational at delivery:
→ Email verification — triggered at sign-up
→ Password reset
→ Welcome email — triggered after first login
→ Onboarding sequence — day 1, day 3, day 7
→ Payment confirmation
→ Payment failed alert
→ Subscription renewal reminder
→ Subscription cancellation confirmation
All emails must be tested across major clients (Gmail, Outlook, Apple Mail) and delivered with consistent
branding placeholders ready for the design team to finalize visually.

3. Onboarding Flow

Automated onboarding email sequence triggered upon sign-up.
In-app onboarding checklist to guide users through first key actions and drive activation within the first 7
days.

4. Subscription & Payment System
Full Stripe integration across the three plans (Starter, Growth, Enterprise).
→ Subscription creation, upgrade, downgrade, and cancellation flows
→ Webhook handling for payment events (failed payment, renewal, cancellation)
→ Customer billing portal access
→ Usage-based limits enforced per plan tier

5. Core Platform Features
AI visibility scoring engine using Claude API.
Brand audit logic across ChatGPT, Perplexity, Gemini, and other AI search engines.
AEO and GEO recommendations generated per brand analysis.
Dashboard displaying visibility scores, citations, and competitive positioning.
Multi-tenant architecture ensuring full data isolation between accounts.

6. Notifications & Alerts
Email notifications for key events (new audit results, score changes, plan expiration, payment issues).
In-app notification system for real-time updates.

7. API & Integrations
RESTful API with proper authentication (API keys per tenant).
Webhook support for enterprise integrations.
Rate limiting and usage tracking per plan.

8. Infrastructure & Security
SOC2-ready baseline: audit logs, encryption at rest and in transit, secure secret management.
Environment separation (dev, staging, production).
Automated backups and error monitoring (Sentry or equivalent).

9. Admin Dashboard

A fully operational internal admin dashboard must be built, accessible only to the Seenly team. This
dashboard gives full visibility and control over the entire platform — users, subscriptions, AI audit activity,
and business performance.
User & Account Management
→ Full list of all registered users with search and filter (by plan, status, signup date, country)
→ View, edit, suspend, or delete any user account
→ Manually upgrade or downgrade a user's subscription plan
→ Impersonate a user account for support purposes
→ View full activity log per user (audits run, logins, plan changes)
Subscription & Revenue KPIs
→ Total MRR (Monthly Recurring Revenue) and ARR
→ MRR breakdown by plan (Starter / Growth / Enterprise)
→ Number of active, churned, and trialing subscriptions
→ Churn rate (monthly)
→ New subscriptions vs cancellations over time (chart)
→ Upgrade and downgrade events
→ Failed payments — list and retry options
Platform Usage & AI Activity KPIs
→ Total number of AI brand audits run (daily / weekly / monthly)
→ Average audits per user
→ Most audited brands and industries
→ AI engines queried (ChatGPT, Perplexity, Gemini, Claude) — volume per engine
→ Average AI visibility score across all users
→ Top performing brands in AI search (anonymized benchmarks)
Growth & Acquisition KPIs
→ Total signups over time
→ Waitlist size and conversion rate (waitlist → paid)
→ Daily Active Users (DAU) and Monthly Active Users (MAU)
→ Activation rate (users who ran at least one audit within 7 days)
→ Retention cohort view (week 1, week 2, week 4)
Email & Onboarding Monitoring
→ Email delivery rates, open rates, and click rates per email type
→ Onboarding checklist completion rate per user
→ Drop-off point in onboarding funnel
Support & Operations
→ Manual coupon and promo code creation

→ Refund management directly from the dashboard
→ System health status (API uptime, Claude API usage and cost, error rate)
→ Audit log of all admin actions for compliance
Admin Access & Security
→ Admin dashboard accessible only to authorized Seenly team members
→ Two-factor authentication (2FA) mandatory for all admin accounts
→ Role-based admin access (Super Admin, Support, Finance) with scoped permissions
Data Export
→ Export full user list to CSV (name, email, plan, signup date, status)
→ Export revenue data to CSV (MRR, transactions, refunds)
→ Export AI audit activity to CSV (user, brand audited, score, date)

10. Compliance, Data & Language
RGPD & Data Privacy
→ Cookie consent banner compliant with GDPR (accept / reject / customize)
→ Right to deletion — users can request full account and data deletion from settings
→ Right to data portability — users can export their own data
→ Data stored exclusively on European servers (EU-based infrastructure required)
→ Privacy Policy and Terms of Service pages linked at signup and in footer
→ Data processing agreement (DPA) ready for Enterprise clients
Language
→ Platform built in English as the primary language
→ Architecture must support future multilingual expansion (i18n-ready) without a full rebuild
