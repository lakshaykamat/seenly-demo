SECTION 4

Crawl & Extraction System
1

Page Discovery
Try sitemap variants → select top 10–20 business URLs. Fallback: homepage fetch + internal link
extraction. Exclude blog, careers, legal, parameterized URLs.

2

Content Extraction
Fast HTML extraction first. If content <800 chars → JS-render fallback (Firecrawl/Playwright), capped to
M pages.

3

Blocked Detection
Detect 403/401/429, Cloudflare pages, empty body. Return structured state: ok | partial | blocked
| unreachable + confidence 0–100. Auto-add "AI Not Readable" recommendation.

4

Evidence Artifacts
Store per-page: extraction method, text length, titles, H1/H2, JSON-LD types, internal links count,
keyword list.

SECTION 5

Business Understanding & Query Generator
A 3-step grounded engine — deterministic and explainable.

Step A: Profile Extraction
From page evidence → company summary, 3–6 offer clusters (name, keywords ≥2, target buyers, confidence). Fail-fast if no cluster meets minimum signal.

Step B: Query Generation
Structured library: queries per cluster, types (high-intent / informational / competitive), geo-tagged, versioned query packs per dimension scope.

Step C: Brand-Only Fallback
When extraction fails: domain name + brand tokens, 6–12 safe generic queries. Labeled "low confidence / fallback mode." Limited competitor inference.
